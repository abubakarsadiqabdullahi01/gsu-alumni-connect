HOW IT WORKS
────────────

User uploads file → Job created (QUEUED)
                  → Self-trigger fires immediately
                  → Cron processes job within 100ms
                  → Processing starts
                  → Status: QUEUED → RUNNING → COMPLETED

If self-trigger fails:
  → Next cron minute (max 60 sec wait)
  → Picks up QUEUED job
  → Processing starts
  → Same result
