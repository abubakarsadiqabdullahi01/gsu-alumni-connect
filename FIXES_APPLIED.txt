❓ TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

If test:connections fails:
  1. Verify .env.local has correct URLs
  2. Check internet connection
  3. Verify Neon & Upstash services are running

If worker still crashes:
  1. Check connection test output for which component fails
  2. Increase socket timeout further if needed
  3. Check Redis/Database logs for specific errors

If import still stalls:
  1. Look for: ECONNRESET or lock renewal errors
  2. Run: pnpm queue:check
  3. Restart: pnpm worker:import
