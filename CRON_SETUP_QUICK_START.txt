🎯 HOW IT WORKS
═══════════════════════════════════════════════════════════════════════════

Two-Tier Processing:

Tier 1: INSTANT (Self-Trigger)
  Upload File
       ↓
  Job Created
       ↓
  [Fire-and-forget] /api/cron/process-import
       ↓
  Processing Starts (within 100ms)

Tier 2: SAFETY NET (Scheduled Cron)
  Every Minute:
  - Check for QUEUED jobs
  - Check for stalled RUNNING jobs (heartbeat > 2 min)
  - Pick oldest one and process
  - If self-trigger failed, cron catches it


⚙️ KEY CONFIGURATION
═══════════════════════════════════════════════════════════════════════════

vercel.json:
  Schedule: "* * * * *" (every minute)
  Path: /api/cron/process-import

maxDuration: 300 seconds (5 minutes)
  └─ Enough to process 500-1000 rows
  └─ For larger: split file or upgrade plan

Cron Security:
  └─ Protected by CRON_SECRET in Authorization header
  └─ Vercel automatically passes: Bearer {CRON_SECRET}
