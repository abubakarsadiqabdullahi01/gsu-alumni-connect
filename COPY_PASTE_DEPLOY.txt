Run these commands in PowerShell in your project directory:

cd c:\Users\user\Documents\gsu-alumni-connect

# See what's ready to commit
git status

# Add everything
git add .

# Commit
git commit -m "feat(cron): add automatic job processing on Vercel

- Add cron endpoint: app/api/cron/process-import/route.ts
- Add cron config: vercel.json (every minute)
- Add self-trigger: app/api/import-jobs/route.ts
- Complete documentation for deployment"

# Push to GitHub
git push origin main


═══════════════════════════════════════════════════════════════════════════

After the push completes, do this:

1. Generate CRON_SECRET
   node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
   (Copy the output)

2. Go to Vercel
   https://vercel.com/projects/gsu-alumni-connect/settings/environment-variables

3. Add environment variable
   Name: CRON_SECRET
   Value: [paste the output from step 1]
   Click: Add

4. Wait 30 seconds, then check
   https://vercel.com/projects/gsu-alumni-connect/settings/cron-jobs

   You should now see:
   ✅ /api/cron/process-import (Every 1 minute)
