✨ TWO-TIER PROCESSING ARCHITECTURE
════════════════════════════════════════════════════════════════════════════

Tier 1: INSTANT (Self-Trigger)
  Upload → Job Created → Self-trigger fires → Processing starts within 100ms
  
  Gives instant start with no waiting

Tier 2: SAFETY NET (Scheduled Cron)
  Every minute: Vercel calls /api/cron/process-import
  └─ Picks up any QUEUED jobs
  └─ Recovers stalled RUNNING jobs (heartbeat > 2 min)
  └─ Ensures no job is ever stuck forever
  
  Fallback if self-trigger fails (max 60 second wait)
