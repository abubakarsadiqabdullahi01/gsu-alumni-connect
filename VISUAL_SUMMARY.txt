🏗️  ARCHITECTURE
═══════════════════════════════════════════════════════════════════════════

    Vercel (Serverless)
    ├─ Upload file
    └─ Queue to Redis
         ↓
    Redis (Cloud Queue)
    ├─ Stores jobs
    └─ Accessible anywhere
         ↓
    Worker (Local/Railway/Render)
    ├─ Processes jobs
    └─ Updates progress
         ↓
    Database (Neon PostgreSQL)
    └─ Stores results


🌐 DEPLOYMENT OPTIONS
═══════════════════════════════════════════════════════════════════════════

Option A: Local Machine (NOW) ✅
  $ pnpm worker:import
  Pros: Easy, no setup
  Cons: Your machine must stay on

Option B: Railway (RECOMMENDED) ⭐
  $ npm i -g @railway/cli && railway up
  Pros: 24/7, easy, free tier
  Cons: Need Railway account

Option C: Render
  Visit https://render.com
  Connect repo, set: pnpm worker:import
  Pros: Auto-scale, free tier
  Cons: Slower deployment

🔧 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

Job stuck in "processing"?

  → Fix: pnpm worker:import (restart)

Redis connection error?
  → Check: echo $UPSTASH_REDIS_REST_TOKEN
  → Fix: Verify .env.local

Job not starting?
  → Check: pnpm queue:check
  → Fix: Start worker if stopped
